# VocalFolio visual identity

- `vocalfolio-logo.png`: original generated PNG, 1254 × 1254 pixels, RGBA, transparent outside the tile.
- `../src/Assets/vocalfolio-icon.png`: 256 × 256 PNG used in the application header.
- `../src/Assets/vocalfolio.ico`: Windows ICO with 16, 20, 24, 32, 40, 48, 64, 96, 128 and 256 pixel frames, preserving alpha.

Created on 29 October 2026 using the built-in `image_gen` tool. PNG resizing and ICO container conversion are deterministic; the artwork itself was generated with the prompt below. Assets are included under the project's MIT license; this does not constitute a trademark registration.

## Generation prompt

Use case: logo-brand. Create ONE final premium Windows app icon for VocalFolio, a private local meeting recording and transcription application. Square canvas, centered rounded-square midnight navy tile (#101725), genuinely transparent outside its rounded corners. Large simple custom mint-green (#BBECDD) symbol with bold clean consistent geometric strokes: merge a recognizable elegant letter V / voice waveform with the outline of a folded document page (folio). The silhouette should feel like voice becoming a written record. At most three to five broad graphic elements, very legible at 16px and 32px. Symbol fills about 65-70% of tile with generous optical margins. Flat vector-like precision, tasteful modern Windows desktop branding, excellent contrast, no intricate thin lines. No letters or words other than the abstract V form, no text, no mockup, no perspective, no drop shadow outside the tile, no watermark, no microphone clip-art, no multiple variants. Deliver a crisp high-resolution single icon with alpha transparency.
