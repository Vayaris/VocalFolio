# Changelog

## v1.0.0 — First public release

- Windows x64 portable executable with local CPU transcription.
- Microphone + selected PC output capture, levels, pause/resume.
- NVIDIA Nemotron and Parakeet model management with verified downloads/imports.
- Speaker attribution, manual names, edits, TXT/SRT exports and meeting history.
- Bounded WASAPI playback, selectable listening output and audio folder shortcut.
- Progress percentage and estimated remaining time.
- Recording authorization reminder, privacy documentation, MIT code license and third-party attribution.

The earlier internal prototypes used different version numbers; this tag is the first public VocalFolio release. Known limits are documented in README and VALIDATION.
